# 🤖 ToZtrading_Bot — Financial Intelligence AI

Un bot Telegram di analisi finanziaria avanzata guidato da **Gemini 3.6 Flash** e grounded con dati di mercato in tempo reale da **Yahoo Finance**.

---

### 🚀 Caratteristiche Principali

* 📊 **/top_picks**: Analisi sintetica dei mercati basata sul modello a 3 parametri (Watchlist, Noise vs Signal, Catalizzatori).
* 💼 **/investi [importo]**: Master Plan di allocazione del capitale con stima del rendimento annuo e max drawdown.
* 🫧 **/fomo_meter [ticker]**: Calcolo dell'indice di bolla basato su metriche quantitative reali (P/E, prezzo, variazione dai massimi a 52 settimane).
* 🦋 **/effetto_farfalla [evento]**: Analisi macroeconomica per individuare vincitori e vittime collaterali di secondo livello.
* 🔥 **/roast [titoli]**: Stress-test spietato del portafoglio per rilevare problemi di correlazione e diversificazione.

---

### 🛠️ Tech Stack

* **Language**: Python 3.9+
* **AI Engine**: Google Gemini API (`google-genai` SDK)
* **Market Data**: Yahoo Finance (`yfinance`)
* **Bot Framework**: `python-telegram-bot`
